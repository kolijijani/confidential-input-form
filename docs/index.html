// Secret Vault

A one-shot, local form for handing an API key, password, certificate or config file to an AI agent — without pasting it into chat, where it lands in model context, transcripts and tool logs.

InstallClone, run, or install as a command with pipx or uvx. Standard library only. UsageAdaptive fields, raw-file mode, expiry, audit log. Use with an agentClaude Code, Codex, Cursor, Hermes — where the skill goes. Security modelWhat it protects, what it does not, and how to report a flaw.

Why this exists

An agent asks for a key. You paste it into the chat box. That value is now part of the conversation history, the provider's request, the session transcript on disk, and possibly a tool log — and you cannot take it back.

Secret Vault replaces that paste with a form on your own machine. The agent declares which fields it needs; you type the value into the page; it is written straight to a protected local file with mode 0600. The server accepts exactly one submission and exits.

How it works

StageResponsibilitySecret exposure
AgentCreates a JSON form specificationSees field definitions, never values
Local serverServes a random-token, one-shot formHolds values only while writing
Your browserSubmits over localhost or a trusted private networkYou control the entry point
Protected targetReceives an atomic write with mode 0600Values remain local

Quickstart

git clone https://github.com/kolijijani/secret-vault.git
cd secret-vault
python3 scripts/secret_form.py --spec examples/api-key.json

The command prints a one-time URL and waits for one submission:

URL: http://127.0.0.1:8731/?t=<random-token>
TARGET: /home/user/.config/secret-vault/provider.env
EXPIRES: 900s
Waiting for one submission...

Open that URL on the same machine. After the value is saved the server writes the target file and exits; if nobody submits before the deadline it exits and writes nothing.

What it does

  • Keeps secret values out of chat, model context and request logs.
  • Lets the agent adapt title, labels, field types, optional fields and target file per task.
  • Supports visible text, masked secrets, long text, code, file uploads and paste-or-upload fields.
  • Writes KEY=VALUE env files or complete raw files such as JSON, YAML, PEM and config files.
  • Atomic mode-0600 writes, symlink rejection, random server-side upload names.
  • Random URL token plus a locked single-claim submission state.
  • Closes itself after a deadline (--expire-minutes, 15 by default) and refuses wildcard binds.
  • Preserves binary uploads with bounded, standards-aware multipart parsing.
  • Runs on the Python standard library — no package installation required.
  • Optional value-free audit line per submission (--audit-log).
  • Ships an agent-ready SKILL.md, an install.sh, examples, CI and 33 tests.
Secret Vault is a local handoff utility, not an internet-facing secret manager. Use localhost or a trusted private network such as Tailscale or a VPN.
