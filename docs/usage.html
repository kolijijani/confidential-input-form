// Usage

The agent writes a small JSON spec. The form adapts to it. You submit once.

Start a form

python3 scripts/secret_form.py --spec examples/api-key.json

Or pass the spec on stdin:

echo '{"title":"Provider key","target":"~/.config/secret-vault/provider.env","mode":"env",
"fields":[{"key":"API_KEY","label":"API key","type":"password"}]}' \
  | python3 scripts/secret_form.py --spec -

Adaptive form

The design stays fixed; the content changes per task. Field types, labels, optional flags, the target file and the page title all come from the spec:

{
  "title": "Email delivery setup",
  "subtitle": "Provide the sender identity and signing credential",
  "target": "~/.config/secret-vault/mail.env",
  "mode": "env",
  "fields": [
    {"key": "MAIL_FROM", "label": "Sender email", "type": "text"},
    {"key": "SIGNING_KEY", "label": "Signing key", "type": "password"},
    {"key": "MAIL_CONFIG", "label": "Config bundle", "type": "dual", "optional": true}
  ]
}

Field types

TypeIntended use
textVisible context such as email, account ID, region or project name
passwordMasked API keys, passwords, tokens and signing secrets
textareaMulti-line notes or short text blobs
codeMonospace JSON, YAML, PEM, config or code
fileFile upload
dualLets the user choose paste or upload
optional: trueSkips an empty field

Raw file mode

Use mode: "file" when the submitted content is the target file — a JSON service account, a PEM key, a YAML config:

python3 scripts/secret_form.py --spec examples/config-file.json

Expiry and single use

The form is one-shot: the first successful save closes it. It also has a deadline, so an abandoned link never stays open.

python3 scripts/secret_form.py --spec examples/api-key.json --expire-minutes 20

--expire-minutes defaults to 15; pass 0 to disable the deadline. When the deadline passes the page returns 410 Gone and no values are written. After the process exits the port is closed and the token is useless.

For OS-level belt-and-braces on a shared machine, wrap the process in a hard kill:

systemd-run --user --unit=secret-form --property=RuntimeMaxSec=900 --collect python3 scripts/secret_form.py --bind 127.0.0.1 --spec examples/api-key.json

Audit log

--audit-log PATH appends one line per submission with the timestamp, outcome, field names and byte count — never values. It is written 0600 and is useful when an agent must prove a handoff happened without touching the secret.

2026-10-22T04:31:07+00:00	saved-env	fields=MAIL_FROM,SIGNING_KEY	bytes=88

Command options

--audit-lognoneAppend a value-free line per submission
--version—Print the version and exit

Open the form from another device

Wildcard binds are refused unless you pass --allow-wildcard, so a typo cannot quietly expose the form on every interface. Bind the machine's IPv4 address on a trusted VPN or LAN instead:

python3 scripts/secret_form.py --bind 100.x.y.z --spec examples/api-key.json
Never bind to a public interface without a protected tunnel and TLS proxy.
