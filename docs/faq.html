// FAQ & troubleshooting

The problems people actually hit, and the limitations worth knowing before you rely on this.

The URL works only on the server machine

The secure default is 127.0.0.1. Bind explicitly to a trusted private IPv4 address when another device must open the form:

python3 scripts/secret_form.py --bind 100.x.y.z --spec examples/api-key.json

Never bind to a public interface without a protected tunnel and TLS proxy.

Port already in use

python3 scripts/secret_form.py --port 8732 --spec examples/api-key.json

The page closes after submission

That is expected. A successful submission consumes the token and shuts the server down. Start a new process to collect another value.

A target symlink is rejected

That is deliberate protection against redirecting a secret into an unexpected file. Use a regular file path owned by the current user.

The form expired before I submitted

The deadline defaults to 15 minutes. Restart the process for a fresh token, or raise the deadline with --expire-minutes 30. 410 Gone means nothing was written.

My agent keeps asking me to paste the key in chat

The skill is installed but its script path is wrong, so the agent cannot start a form and falls back to asking. Re-run ./install.sh against the right skill directory, or replace scripts/secret_form.py inside SKILL.md with the absolute path to your checkout.

Can I use it over the internet?

Not directly. Put it behind Tailscale, a VPN, or a TLS proxy you trust. The built-in server is HTTP and has no authentication beyond the random token.

Does it work on Windows?

No. Windows filesystem permission and symlink semantics do not provide the POSIX guarantees this release enforces. Use WSL if you need it on a Windows machine.

Is it a secret manager like Vault or 1Password?

No. It is a handoff tool: one form, one value, one write, then it exits. It does not store, rotate, version or share secrets. Use a real secret manager for anything long-lived.

Limitations, in one list

  • HTTP only; TLS termination belongs to a proxy or private overlay network.
  • IPv6 bind addresses are not supported.
  • Windows is not supported.
  • Single-use by design; no submission history.
  • Does not rotate, revoke or validate the submitted credential.
  • Protecting the destination directory and host remains your responsibility.
