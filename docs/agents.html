SKILL.md is the agent-facing instruction file. scripts/secret_form.py is the tool it calls. Installing the skill does not install the script.

Install

git clone https://github.com/kolijijani/secret-vault.git
cd secret-vault
./install.sh ~/.claude/skills

./install.sh with no argument auto-detects the first existing directory from ~/.hermes/skills, ~/.claude/skills, ~/.agents/skills, ~/.config/agents/skills. Use --dry-run to preview.

Without the installer, copy SKILL.md and replace every scripts/secret_form.py with the absolute path to your checkout. If you installed the CLI instead, replace it with secret-vault.

Why the path matters

SKILL.md ships with scripts/secret_form.py, a repository-relative path. Copy only the markdown and the agent will call a script that does not exist — the failure mode is a confused agent asking you to paste a key into chat, which is exactly what this project prevents.

Verify the handoff works

python3 scripts/secret_form.py --version

Then ask the agent for a form and confirm the page shows // secret_vault, LIVE / SINGLE USE and a countdown. If the agent shows you a secret value in chat, stop and re-read the skill's Rule (never break) section.

Give the agent the rule, not the value

The skill's core instruction is one line: when a task needs a credential, start a form and give the user the URL — never ask for the value in chat. Everything else in the skill exists to make that work in practice: choosing field types, choosing the target file, handling expiry, and proving the handoff with the audit log.
