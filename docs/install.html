// Install

Three ways in: run from a checkout, install as a command, or install the agent skill. None of them need a third-party Python package.

Requirements

  • Linux or macOS with Python 3.10 or newer
  • A modern browser
  • Localhost, or a trusted private network when opening the form from another device
  • Chrome or Chromium only if you want to regenerate the README screenshot

Run from a checkout

git clone https://github.com/kolijijani/secret-vault.git
cd secret-vault
python3 scripts/secret_form.py --version

Install as a command

pipx install agent-secret-form
uvx --from agent-secret-form secret-vault --version

The distribution on PyPI is agent-secret-form; the console command stays secret-vault. Installing from Git also works:

pipx install git+https://github.com/kolijijani/secret-vault.git
Do not pip install secret-vault: that name on PyPI belongs to an unrelated project.

Install the agent skill

The installer copies SKILL.md into the agent's skill directory and rewrites the script path to your checkout:

./install.sh              # auto-detects ~/.hermes/skills, ~/.claude/skills, ~/.agents/skills
./install.sh ~/.claude/skills   # or name the directory explicitly
./install.sh --dry-run          # preview without writing

See Use with an agent for the per-agent matrix.

Verify

python3 scripts/secret_form.py --version

Then start the example and confirm the page shows // secret_vault, LIVE / SINGLE USE and a countdown.

Uninstall

pipx uninstall secret-vault

Remove the skill directory the installer created, and any ~/.config/secret-vault/ files you no longer want.
